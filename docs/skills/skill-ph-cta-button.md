# PH CTA Button

Replace `cta_button_shape` drawables (light and dark) with a proper `<shape/>` using
`ph_cta_color`

## Source

[View skill on GitHub](https://github.com/yevhenZ-rounds/TheRoundersKnowledge/blob/main/skills/PhCtaButton/SKILL.md)

## What it covers

- Finding every `cta_button_shape.xml` reference for light and dark themes
- Replacing them with a solid `@color/ph_cta_color` shape
- Setting 12dp corner radii on all four corners (adapt color/corners as needed)
